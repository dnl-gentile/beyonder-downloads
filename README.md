# Beyonder: instaladores da mesa

Aqui ficam só os instaladores do Beyonder para os jogadores da mesa. Não há código-fonte neste repositório.

Para entrar numa sessão, use o link de convite que o mestre mandou: a página do convite explica cada passo.

- **Windows:** baixe `Beyonder-Setup-Windows.exe` na última versão (Releases) e instale. Se o Windows avisar que protegeu o computador, clique em "Mais informações" e depois em "Executar assim mesmo".
- **Mac:** precisa de chip da Apple e macOS 26. Baixe `Beyonder-Mac.zip`, abra o zip e arraste o Beyonder para Aplicativos. Na primeira vez, se o Mac bloquear, vá em Ajustes > Privacidade e Segurança > Abrir mesmo assim.
